# PR Title

feat/FEAPP-420: Add WhatsApp notifications for product updates

## PR Description

### WHAT

This change adds WhatsApp as an optional notification channel for customers who want to receive product listing updates through their WhatsApp numbers.

### WHY

Customers have requested the ability to receive product update notifications through WhatsApp in addition to email.

### Notes

- WhatsApp notifications are optional.
- Email notifications must continue to work for all customers.
- Customers who provide a WhatsApp number should receive notifications through both channels.
- The source branch is the feature branch created from the main development branch.
- The destination branch is the main development branch.
